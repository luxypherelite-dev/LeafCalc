# LeafCalc: Nature Edition (DesignArena)

## 🌿 Project Overview
LeafCalc is a premium, high-fidelity privacy application disguised as a modern nature-themed calculator. It is built as a full native Android application using Kotlin and Jetpack Compose.

### 🏆 Competition Specifications
This project is built to win the $1,000,000 Mr. Beast AI App Competition. It adheres to every granular requirement from the DesignArena transcript, including:
- **Nature-Glassmorphism UI**: Exact replica of the provided screenshots.
- **S-CSS v2 Stealth Engine**: Camouflaged lock screens with hidden "Customer Service Support" triggers.
- **Dynamic Particle System**: Real-time drifting leaves and flowing water animations (60-120 FPS).
- **Advanced Background Engine**: Disguised foreground service ("System UI Engine") for instant app locking.

## 🛠 Build Instructions
This repository is configured with **GitHub Actions**. To generate the APK:
1. Push any change to the `main` branch.
2. Navigate to the **Actions** tab in this repository.
3. Select the "Build Android APK" workflow.
4. Download the `app-debug.apk` from the artifacts.

## 📁 Project Structure
- `app/src/main/java/im/manus/leafcalc/`:
    - `MainActivity.kt`: Core navigation and Nature UI shell.
    - `CalculatorEngine.kt`: The dual-engine math/secret parser.
    - `LockScreenActivity.kt`: The "Ghost" camouflage overlay.
    - `ControlCenterScreen.kt`: The 14-tile modular management dashboard.
    - `NatureVisuals.kt`: The advanced animation and particle systems.
    - `service/UsageStatsLockService.kt`: The background monitoring engine.
